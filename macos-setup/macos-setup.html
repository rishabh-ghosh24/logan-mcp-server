Credential: logan.key is the approved shared automation1 key. Never commit it to Git. Deliver the package only through the approved internal secure channel.

Install

  1. Extract the private package.
  2. Double-click Install-Logan-MCP.command.
  3. Enter the user's identity in firstname.lastname format.
  4. Require the SSH test and installation to succeed.
  5. Restart Codex completely.

The installer backs up the existing Codex config, migrates the old logan-mcp entry, pins automation1's SSH host key, and creates assurance-logan through /opt/logan-mcp/bin/admin-launch.

Test

Use only the assurance-logan MCP server. Test the connection.

Then use Assurance Logan normally. This unrestricted package is not for CAM users.

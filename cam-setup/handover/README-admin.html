Assurance Logan administrator toolkit

Extract the complete ZIP first. Each numbered file is a self-contained action; no Git checkout or SSH alias is required.

1. Install your own unrestricted profile

Run the file beginning 1-Install, enter firstname.lastname, then restart Codex.

2. Add a CAM

Run 2-Provision-CAM. Enter the CAM ID, customer numbers, and false for delivery. Confirm with YES. Send the generated logan-cam-<id>.zip only to that CAM through an approved secure channel.

3. Revoke a CAM

Run 3-Revoke-CAM, enter the CAM ID, inspect the assignment shown, and type the exact requested revocation confirmation.

The generated CAM ZIP already contains both macOS and Windows one-click installers. Keep this administrator ZIP restricted: it contains the shared VM private key.

Assurance Logan user setup

One action: extract this ZIP and run the installer. Do not move or rename individual files first.
  1. Close Codex App.
  2. Run Install-Logan-MCP.command on macOS, or Double-Click-to-Install.cmd on Windows.
  3. Enter your name as firstname.lastname.
  4. Reopen Codex and ask: Connect to the assurance-logan MCP server.

This package provides unrestricted Assurance-team access. Keep it in the approved team only: it contains the shared VM private key.
